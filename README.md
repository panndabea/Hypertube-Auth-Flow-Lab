# Hypertube Auth Flow Lab

## Usage
1. Open `/tmp/workspace/panndabea/Hypertube-Auth-Flow-Lab/index.html` in any modern browser.
2. Click a screen in **Flow Screens** (left panel).
3. Use the action buttons in the center panel to simulate auth events.
4. Check **Inspector** and **Event Timeline** for state, route, request/response, errors, QA case, and security notes.
5. Use **Reset simulation** to restart and **Export flow log** to download `hypertube-auth-flow-log.json`.
